# CapCut Agent Playbook
# Agent 101 — Chrome Browser Automation for capcut.com

Last updated: 2026-06-24
Maintained by: Agent 101 / Argentum OS

---

## Purpose

This playbook defines the exact step-by-step browser actions Agent 101 must follow
when the operator instructs it to edit a clip in CapCut. The agent uses the
Chrome browser workspace (supervised Chromium) to operate capcut.com autonomously,
streaming each step to the operator via SSE.

All CapCut sessions require a **Human Gate approval** before the export/download
step. The operator retains full control over what leaves CapCut.

---

## Pre-Flight Checklist

Before opening CapCut, Agent 101 must confirm:

- [ ] A rendered clip file exists at a known local path (e.g. `data/clips/CLIP_ID.mp4`)
- [ ] The operator has confirmed they are logged into capcut.com (Human Gate: `capcut_login_confirmed`)
- [ ] A CapCut edit spec is present (see Edit Spec Format below)
- [ ] Practice mode clips are labeled as PRACTICE — never upload without operator consent

---


## Step-by-Step Browser Automation

### Phase 1 — Open CapCut

**Step 1.1** — Navigate to CapCut
```
action: navigate
url: https://www.capcut.com/create
wait_for: .editor-page or .project-list or [data-testid="new-project-btn"]
timeout: 15s
on_failure: emit_error("CapCut failed to load — check login status")
```

**Step 1.2** — Check login state
```
action: check_element
selector: [data-testid="user-avatar"] OR .user-profile-icon OR .login-btn
if_found_login_btn:
  emit_sse("CapCut: not logged in — Human Gate required")
  request_human_approval(action="capcut_login", message="Please log in to capcut.com in the browser window, then approve this gate to continue")
  wait_for_approval()
```

**Step 1.3** — Create new project
```
action: click
selector: [data-testid="new-project-btn"] OR button:contains("New project") OR .create-btn
wait_for: .upload-area OR .import-dialog OR .timeline-editor
```

### Phase 2 — Import the Clip

**Step 2.1** — Trigger file import
```
action: click
selector: [data-testid="upload-btn"] OR .upload-local OR button:contains("Upload")
```

**Step 2.2** — Upload clip file
```
action: file_upload
file_path: {edit_spec.clip_path}
selector: input[type="file"]
wait_for: .clip-thumbnail OR .media-item OR .track-clip
timeout: 60s
on_failure: emit_error("Upload failed — file may be too large or format unsupported")
```

**Step 2.3** — Add clip to timeline
```
action: click
selector: .add-to-timeline-btn OR [data-testid="add-clip"] OR .clip-thumbnail
# If drag required:
action: drag
from: .media-item:first-child
to: .timeline-track:first-child
wait_for: .timeline-clip-block
```

**Step 2.4** — Confirm clip is on timeline
```
action: check_element
selector: .timeline-clip-block OR .video-track .clip
if_not_found: emit_error("Clip did not land on timeline")
```

### Phase 3 — Set Aspect Ratio

**Step 3.1** — Open ratio settings
```
action: click
selector: [data-testid="ratio-btn"] OR .ratio-selector OR button:contains("9:16")
```

**Step 3.2** — Select 9:16
```
action: click
selector: [data-value="9:16"] OR .ratio-9-16 OR li:contains("9:16")
wait_for: canvas aspect change (canvas height > canvas width)
```

### Phase 4 — Auto Reframe (if enabled)

```
condition: edit_spec.reframe.enabled == true

action: click
selector: [data-testid="smart-cut"] OR .auto-reframe-btn OR button:contains("Auto reframe")

# Select target type
action: click
selector: [data-value="action"] OR .reframe-action-center OR option:contains("Action")

action: click
selector: .apply-reframe OR button:contains("Apply")
wait_for: .reframe-complete OR .timeline-clip-block (updated)
timeout: 30s
emit_sse("CapCut: auto-reframe applied")
```

### Phase 5 — Auto Captions (if enabled)

```
condition: edit_spec.captions.enabled == true

action: click
selector: [data-testid="captions-btn"] OR .auto-caption OR button:contains("Auto captions")

# Select language (default English)
action: click
selector: .language-select option[value="en"] OR [data-lang="en"]

action: click
selector: .generate-captions-btn OR button:contains("Generate")
wait_for: .caption-track OR .subtitle-block
timeout: 45s
emit_sse("CapCut: captions generated — reviewing style")

# Apply caption style
action: click
selector: .caption-style-tab OR [data-testid="caption-styles"]

# Select gaming bold style (closest match)
action: click
selector: .style-card:nth-child(3) OR [data-style="bold"] OR .caption-preset:contains("Bold")

emit_sse("CapCut: caption style applied")
```

### Phase 6 — Hook Text Overlay (if hook_text provided)

```
condition: edit_spec.hook_text is set

action: click
selector: [data-testid="text-btn"] OR .add-text OR button:contains("Text")

action: click
selector: .add-text-track OR button:contains("Add text")

action: type
value: {edit_spec.hook_text}
selector: .text-input OR .text-editor-field

# Position at top of frame
action: drag
from: .text-overlay-handle
to: canvas top-center (y: 10%, x: 50%)

# Set duration to match clip start (first 3 seconds)
action: trim_clip
track: .text-track .clip
end_handle: 3s mark

emit_sse("CapCut: hook text overlay added")
```

### Phase 7 — Preview

```
action: click
selector: .preview-play-btn OR [data-testid="play"] OR button[aria-label="Play"]
wait: 5s
action: click
selector: .preview-play-btn (pause)
emit_sse("CapCut: preview complete — ready for operator review")
```

### Phase 8 — Human Gate: Operator Review

```
action: request_human_approval
gate_id: capcut_export_approval
message: "CapCut edit is complete. Preview the result in the browser, then approve to export or send_back with notes."
blocking: true

on_send_back:
  notes = approval.notes
  emit_sse("CapCut: operator requested changes — {notes}")
  # Re-enter loop at relevant phase based on notes
  goto: relevant phase

on_approved:
  emit_sse("CapCut: export approved — starting download")
  goto: Phase 9
```

### Phase 9 — Export

**Step 9.1** — Open export dialog
```
action: click
selector: .export-btn OR [data-testid="export"] OR button:contains("Export")
wait_for: .export-dialog OR .export-settings-panel
```

**Step 9.2** — Set export settings
```
action: select
selector: .resolution-select
value: "1080p"

action: select
selector: .format-select
value: "mp4"
```

**Step 9.3** — Start export
```
action: click
selector: .start-export-btn OR button:contains("Export") (inside dialog)
wait_for: .export-complete OR .download-link OR .export-progress:contains("100%")
timeout: 120s
emit_sse("CapCut: export complete")
```

**Step 9.4** — Trigger download
```
action: click
selector: .download-btn OR a[download] OR button:contains("Download")
emit_sse("CapCut: download triggered — check your browser downloads folder")
```

## Error Recovery Rules

| Error | Recovery Action |
|---|---|
| CapCut not loaded after 15s | Retry navigate once, then Human Gate |
| File upload fails | Check file format (must be mp4/mov), check size < 4GB |
| Auto-reframe spinner hangs >60s | Skip reframe, emit warning, continue |
| Caption generation fails | Skip captions, emit warning, note in output |
| Export fails | Screenshot error, emit to operator, request Human Gate |
| Login required mid-session | Request Human Gate `capcut_login_confirmed` |

## Output

After successful export, Agent 101 must:

1. Log the edit session to `data/state.json` under `artifacts` with:
   - `clip_id`
   - `capcut_session_timestamp`
   - `edits_applied` (array of phases completed)
   - `export_path` (if download was confirmed)
   - `human_gate_log` (approval ID + timestamp)

2. Update the clip candidate status to `packaged`

3. Create a posting draft pointing to the exported file

4. Emit SSE: `"CapCut session complete — posting draft created for review"`

---

## What Agent 101 Must Never Do in CapCut

- Never publish directly to TikTok/Instagram from CapCut — that requires a separate Human Gate through the posting pipeline
- Never accept CapCut's "share to TikTok" prompt — always export locally first
- Never store CapCut login credentials — operator manages their own session
- Never upload clips marked PRACTICE MEDIA to CapCut without explicit operator confirmation
- Never proceed past Phase 8 without an approved Human Gate

---

## Selector Fallback Strategy

CapCut's frontend updates frequently. If a primary selector fails:

1. Try the `data-testid` variant
2. Try the text-content variant (`:contains()`)
3. Try positional heuristic (e.g., `.toolbar button:nth-child(3)`)
4. Take a screenshot and emit it to the operator with SSE: `"CapCut: UI changed — screenshot attached, human assist needed"`
5. Request Human Gate to let operator take over
