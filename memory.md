# Argentum Memory Behavior

Primary long-term memory lives in the local Obsidian vault:

`Argentum-Brain`

Argentum OS is the command center, OpenClaw is the action gateway, Claude Code is the development worker, and Agent 1010 is the supervised orchestrator.

## Rules

1. Search existing Obsidian notes before creating new notes.
2. Append to existing notes whenever possible.
3. Every new business note must link from a business master file.
4. Every agent must have one profile file.
5. Every skill must have one skill file.
6. Every workflow must have one workflow file.
7. Daily notes summarize work, decisions, errors, lessons, and next steps.
8. Do not store secrets in memory.
9. Do not delete or overwrite notes without explicit approval.
10. Keep Human Gate approvals visible without exposing credentials.
